# quanttide-insight-of-payment-engineering

量潮支付工程洞见 — 记录量潮支付工程领域的观察、洞察与经验总结。

## 概述

本仓库用于维护量潮支付工程领域的洞见信息，包括：

- 行业观察与趋势
- 用户洞察
- 实践经验与教训
- 反思与启示

## 文档

- [领域模型](./model.md) — 根据意图建模的支付工程领域模型:账户、交易、余额、优惠券、代金券、计费规则与关键场景
- [三业务计费同构](./billing-isomorphism.md) — 数据、课堂、云三个业务计费同构的洞察:计费本质是「单价 × 数量」、同构源于商务云分层、工程化落点是行模型、抄结构不抄复杂度
